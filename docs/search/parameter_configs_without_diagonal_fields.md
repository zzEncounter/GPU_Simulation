# 实验方案

## 主实验

### 1. 时延图

展示不同电路和配置下的端到端运行时延，用于比较整体性能。

### 2. Kernel 可重构性

通过改变 kernel 配置参数，展示 SAD kernel 在不同执行配置下的可重构性。图表应突出显示配置变化与运行性能变化之间的关系。

### 3. Breakdown 实验

将总运行时间拆分为以下三个部分：

- 前向（Forward）
- 后向（Backward）
- 其他部分（包括 Hamiltonian、初始化及必要的同步开销）

建议覆盖以下设备和规模：

| 设备 | 电路 | 规模 |
|---|---|---:|
| NVIDIA RTX 6000 Ada | QAOA | 4、16 qubits |
| NVIDIA RTX 6000 Ada | HEA | 4、16 qubits |
| NVIDIA RTX 4090 | QAOA | 4、16 qubits |
| NVIDIA RTX 4090 | HEA | 4、16 qubits |

展示顺序建议为：

1. 时延图
2. Kernel 配置及可重构性图
3. Breakdown 图

## 对比原则

- 每一行、每一列以及跨章节的比较都应保持单变量变化。
- 每次对比只改变一个设置参数，其他参数保持一致。
- 八组示例应覆盖不同参数组合，确保每个目标参数至少在一组对比中发生变化。
- 图表中应明确标注设备、电路、qubits、层数和配置参数。

## 消融实验

参数选择受到多个因素影响，且不同参数的影响程度不同。消融实验需要回答：

- 哪些性能变化由哪些参数引起？
- 哪些参数对前向、后向和其他阶段影响最大？
- 参数组合是否存在明显的协同或冲突效果？

建议对关键参数逐一关闭、替换或固定，并与完整配置进行对比。每组消融实验应保持电路、设备、qubits、层数和重复次数一致。

## Breakdown 实验归属

Breakdown 实验放在主实验章节中，与整体时延图和 kernel 可重构性图一起展示，形成以下完整叙述：

```text
整体时延
  -> Kernel 配置变化带来的性能差异
  -> 前向、后向和其他阶段的时间分解
```
