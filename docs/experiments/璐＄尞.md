# SAD：面向结构化量子电路的 GPU Adjoint Differentiation

## 1. 研究动机

### 1.1 变分量子电路不是任意门流

变分量子算法通常由少数 layer template 反复堆叠而成。例如，hardware-efficient ansatz 交替单比特旋转与固定纠缠层，QAOA 交替 cost 和 mixer，Hamiltonian variational ansatz 按 even/odd bond matching 作用。同一层中的门往往具有对易性、参数共享、固定置换或不变子空间。

通用 statevector 模拟器将电路展开为 gate list，再对每个门调用通用 kernel。这种抽象适合任意电路，却隐藏了决定 GPU 性能的信息：

- 多个门能否在一次 statevector 读写中完成；
- 多个梯度能否在同一层端点归约；
- 连续层能否共享数据布局或消除中间写回；
- 某个操作究竟是对角相位、basis permutation，还是需要 partner amplitude 的非对角变换。

SAD（Structured Adjoint Differentiation）的核心主张是：**对结构化变分电路，adjoint differentiation 的系统优化单位应当是 layer，而不是 gate。** 系统保留 layer 的代数不变量，用不同的 GPU 执行引擎处理旋转、对角、置换和 bond 层，并在层边界联合优化 forward 和 backward。

### 1.2 真正稀缺的资源是 full-state pass

对 \(q\) 个 qubit，statevector 包含 \(N=2^q\) 个 amplitude。`complex<double>` 状态占 \(16N\) bytes；一次最简单的读后写回至少产生 \(32N\) bytes 流量。adjoint 执行还需要 primal 和 adjoint 的双 buffer，大规模时会快速进入带宽主导区。

| q | 一个 complex state | 一次 read+write | 四个 adjoint state buffer |
|---:|---:|---:|---:|
| 20 | 16 MiB | 32 MiB | 64 MiB |
| 22 | 64 MiB | 128 MiB | 256 MiB |
| 24 | 256 MiB | 512 MiB | 1 GiB |
| 26 | 1 GiB | 2 GiB | 4 GiB |
| 28 | 4 GiB | 8 GiB | 16 GiB |

这个成本模型改变了优化重点。对一层 \(q\) 个单比特门，将每个门的复乘减少几条指令通常不如将 \(q\) 次 state pass 压缩为少量 phase；将 diagonal 或 permutation 融合到已有写回也可能比单独优化它们的 kernel 更有价值。

### 1.3 backward 是系统的主要瓶颈

给定

\[
|\psi\rangle=U_{L-1}(\theta_{L-1})\cdots U_0(\theta_0)|\psi_0\rangle,
\qquad
E=\langle\psi|H|\psi\rangle,
\]

adjoint differentiation 包含三段数据流：

1. forward 得到最终 primal state \(|\phi\rangle=|\psi\rangle\)；
2. Hamiltonian 计算 \(|\lambda\rangle=H|\psi\rangle\) 和 energy；
3. backward 按相反顺序同时逆演化 \(|\phi\rangle\) 和 \(|\lambda\rangle\)，并在生成元边界累加梯度。

对 \(U_j(\theta_j)=e^{-i\theta_jG_j/2}\)，梯度可从形如

\[
\operatorname{Im}\langle\lambda_j|G_j|\phi_j\rangle
\]

的 overlap 得到。backward 每个 phase 需要处理两条 state、generator partner 以及一组 reduction，因此不是一个简单的反向 forward。

24q 的完整 8-layer energy+gradient 中，五类电路都由 backward 主导：

| circuit | total | forward | Hamiltonian | backward | backward/forward |
|---|---:|---:|---:|---:|---:|
| RA-HEA | 50.08 ms | 29.0% | 1.9% | 69.0% | 2.38× |
| SU2-HEA | 110.58 ms | 22.1% | 1.5% | 76.4% | 3.45× |
| RZZ-HEA | 128.20 ms | 21.5% | 1.5% | 76.9% | 3.58× |
| QAOA | 96.13 ms | 24.1% | 0.8% | 75.1% | 3.11× |
| XXZ-HVA | 271.66 ms | 23.1% | 0.6% | 76.3% | 3.30× |

这一不对称导出 SAD 的一项基本原则：**forward 和 backward 共享代数表示，但不共享必然相同的 GPU 调度。**

### 1.4 贡献

SAD 的主要贡献如下。

1. **层感知 adjoint 执行。** 系统在 layer 级保留对易关系、参数共享、matching 和实数不变量，使逆演化、generator overlap 和 gradient reduction 可在同一执行边界内完成。
2. **GPU 层级感知旋转引擎。** 系统将 partner amplitude 分布到 warp lanes、thread-local registers 和 CTA shared mailbox，并将一层拆成可非均匀的 phase plan。
3. **代数结构专用的层执行引擎。** 对角层使用 host lookup 和层端点归约，CNOT 层使用置换映射，XXZ 在同 bond 上代数合并 XX/YY/ZZ 并保持 even/odd 依赖。
4. **电路级特化与边界融合。** 包括已知初态直接生成、RA 实数状态、QAOA 共享参数/域墙编码，以及 rotation 与 diagonal/permutation 的写回融合。
5. **可部署的配置规划器。** 将资源敏感的 kernel shape 编译为少量 variant，将 phase division 和 slot map 保留为运行时 metadata，并以端到端 wall time 选择配置。

## 2. 系统概览

### 2.1 电路描述保留语义，而不展开为 gate list

SAD 接收电路类型、qubit 数、layer 数、参数和可选 phase plan。每个 circuit executor 声明三类语义：

- 起始态和首层能否直接生成；
- 每层的操作类型、参数布局和合法融合边界；
- backward 中各生成元的归属、对易关系和逆序。

本文使用的五类电路覆盖了几种典型结构：

| 电路 | 重复层 | 每层参数 | 主要语义 |
|---|---|---:|---|
| RA-HEA | `RY → ring CNOT` | \(q\) | 全实数演化，rotation/permutation 可融合 |
| SU2-HEA | `RY → RZ → ring CNOT` | \(2q\) | 非对角、对角与置换连续边界 |
| RZZ-HEA | `RX → RZ → even RZZ → odd RZZ` | \(3q\) | 同层对角门对易，bond matching |
| QAOA | ring-MaxCut cost `→ RX mixer` | 2 | 层内参数共享，cost 只依赖域墙数 |
| XXZ-HVA | even/odd `RXX → RYY → RZZ` | \(3q\) | 同 bond 对易，相邻 matching 不对易 |

### 2.2 总体数据流

```text
circuit template + parameters
             |
             v
  semantic planner on host
  - layer algebra / shared parameters / invariants
  - phase maps and bond ownership
  - diagonal and initial-state lookup tables
  - kernel-variant and fusion selection
             |
             v
  direct initializer
             |
             v
  layer-specialized forward executors
  [rotation | diagonal | permutation | bond]
             |
             v
  Hamiltonian: lambda = H phi, energy = <phi|lambda>
             |
             v
  reverse layer executors
  - jointly update phi and lambda
  - accumulate all gradients owned by the layer
```

除了将多门合并为更少 kernel，这一设计还避免了为每个参数显式构造导数态。在 backward 中，`phi` 和 `lambda` 在同一层 executor 中一起逆演化；该层拥有的梯度也在数据尚在 registers/shared memory 时归约。

### 2.3 静态 kernel 与动态 plan 的分工

完全静态化会为每个 circuit/size/phase plan 生成新 kernel，导致编译组合爆炸；完全动态化又会把分支、可变长数组和资源上限带入最内层。SAD 使用混合策略。

| 决策 | 实现时机 | 目的 |
|---|---|---|
| scalar type、gate family、slot primitive、forward/backward | C++ template / `if constexpr` | 展开内循环，消除 gate/slot 动态分支 |
| CTA threads \(t\)、register bits \(r\)、mailbox split | 预编译 variant | 它们改变静态 register/shared 需求和 occupancy |
| phase division、physical-to-slot map、bond ownership | host 生成的 device metadata | 在同一 kernel shape 上支持不同 q 和非均匀计划 |
| rotation coefficients、diagonal lookup | 每次参数准备时生成 | 避免 device 内重复三角函数 |
| `(circuit,q)` 的 variant/plan/fusion | runtime dispatch | 选择已验证的端到端配置 |

这个边界对理解配置很重要。例如 `F64r3/B64r4` 只指定 forward/backward 的 CTA 和 thread-local 容量；它没有指定层被分成几个 phase，也没有指定每个 target 位于 lane、register 还是 warp slot。

## 3. GPU 层级感知的旋转引擎

### 3.1 将多个 partner 变换放入一个 tile

RX/RY 在 target qubit \(k\) 上将 \(\psi_i\) 与 \(\psi_{i\oplus 2^k}\) 配对。SAD 将多个 target bit 同时映射到一个 CTA tile，对 tile 只做一次 global load/store，再在三层 GPU 存储中完成多个旋转：

- **lane bits**：32 个 warp lanes 提供 5 个 bit，partner 通过 `shfl_xor` 获取；
- **register bits**：每个 thread 保存 \(2^r\) 个 amplitude，对应 \(r\) 个 thread-local bit；
- **warp bits**：CTA 中的 \(t/32\) 个 warp 提供 \(\log_2(t/32)\) 个 bit，partner 通过 shared mailbox 交换。

一个 shape 的 tile bit 数为

\[
L=5+r+\log_2(t/32).
\]

32 lanes 只固定 lane 层有 5 个 bit，并不限制 \(L=5\)。例如：

| shape | lane bits | register bits | warp bits | tile bits | amplitudes/tile |
|---|---:|---:|---:|---:|---:|
| `t32r2` | 5 | 2 | 0 | 7 | 128 |
| `t64r2` | 5 | 2 | 1 | 8 | 256 |
| `t128r2` | 5 | 2 | 2 | 9 | 512 |
| `t64r4` | 5 | 4 | 1 | 10 | 1024 |
| `t128r3` | 5 | 3 | 2 | 10 | 1024 |

`t64r4` 和 `t128r3` 都覆盖 10 bit，却将一个 partner dimension 分别放入 registers 和 shared mailbox。它们的 global traffic 相同，但 register pressure、barrier 数和 active CTA 不同，因此不能只用 \(L\) 预测性能。

### 3.2 phase plan 同时决定 pass 数和片上交换

当 \(q>L\) 时，rotation layer 被分成多个 phase。每个 phase 都是一次完整 state pass，但其局部成本取决于 target 在三层 slot 中的位置。SAD 将 phase plan 表示为有序的 target class 序列，例如 `L2R2W0-L4R2W0` 表示两个 phase 分别将 4 和 6 个新 target 放入 lane/register slots。这个编码中的 `L/R/W` 分别是 lane/register/warp target 数，不是上式中的 tile 总 bit 数 \(L\)。

调度器考虑三个 layout family：

- **compact**：将当前 target 紧凑地放入所有 slot，优先减少 phase 数；
- **fixed-low-5**：保留物理低 5 bit 与 warp lanes 的连续映射，其他 target 进入 register/warp slots；
- **pair-low-6**：再固定 bit 5，使相邻两个 warp 覆盖连续 64-amplitude 区间。

对 \(q\) 个 target，仅有序 division 就有 \(2^{q-1}\) 种，还未计入 slot assignment。因此 phase 不能简化成“选一个 L，然后从低到高均匀分块”。非均匀 plan 可以改变尾 phase 的资源压力，也可以将更适合融合的 target 放在最后写回。

### 3.3 最少 phase 是首要约束，不是唯一目标

将 pair-low-6 与 fixed-low-5 比较可以分离 pass 数和连续性的作用：

| shape/q | fixed-low-5 phases | pair-low-6 phases | RY forward | RY backward |
|---|---:|---:|---:|---:|
| `t128r2`, 20q | 4 | 5 | pair 慢 11.1% | pair 慢 8.8% |
| `t128r2`, 24q | 5 | 6 | pair 慢 15.9% | pair 慢 9.5% |
| `t64r4`, 24q | 4 | 5 | pair 慢 17.7% | pair 慢 13.7% |
| `t64r4`, 26q | 5 | 5 | pair 快 0.4% | pair 快 3.3% |

前三行中，连续的 64-amplitude 分组无法抵消一次额外 full-state pass。最后一行的 phase 数相同，连续性才带来小而稳定的收益。因此 planner 首先约束在理论最少 phase 附近，再比较 slot locality 与资源成本。

但最少 phase 不是硬编码规则。例如 24q RA 的 forward 使用 L10 compact `10+10+4`，backward 却使用 L10 fixed-low-5 `10+5+5+4`。backward 多一个 pass，但在两条 state 的访存和梯度归约下总时间更低。

### 3.4 mailbox 和 occupancy 是 shape 的交互项

warp bit 需要 shared mailbox 和 CTA barrier。将更多 amplitude 放入 thread-local registers 可减少 mailbox exchange，却会增加 register pressure。将 mailbox 分块可能提高 active CTA，也会增加 barrier 和分块循环。active CTA/SM 因而是 shape 与资源用量推导的结果，不是可独立调节的参数。

一组相同 L9 的 24q 对照显示，消除 warp mailbox 在 phase 数不变时有直接价值，但小 tile 导致的额外 phase 会吞掉该收益。

| gate/direction | `t128r2` L9, full mailbox | `t32r4` L9, no mailbox | 改善 |
|---|---:|---:|---:|
| RX forward | 4.852 ms | 4.400 ms | 9.3% |
| RX backward | 10.785 ms | 9.422 ms | 12.6% |
| RY forward | 4.823 ms | 4.403 ms | 8.7% |
| RY backward | 11.308 ms | 9.661 ms | 14.6% |

Nsight 中两个 shape 的 DRAM traffic 几乎相同，但 forward barrier stall 从 45.98% 降至 0.20%，backward 从 38.45% 降至 1.36%，证明改善来自片上交换而非 global traffic。另一方面，L10 `t64r4` 仍快于无 mailbox 的 L9 shape，说明最优点是 phase 数、registers、warp exchange 和 occupancy 的联合结果，不是将某一项 counter 最小化。

### 3.5 forward/backward 使用方向专用计划

下表列出若干实际计划，展示同一 q 下电路语义和方向如何改变 shape/phase。

| circuit/q | forward | backward | 设计含义 |
|---|---|---|---|
| RA/10 | `t32r2 C[7+3]` | `t32r2 C[L2R2-L4R2]` | 同 shape 下使用非均匀 slot plan |
| RA/24 | `t64r4 C[10+10+4]` | `t64r4 X[10+5+5+4]` | backward 以额外 phase 换取低位连续性 |
| SU2/24 | `t128r2 C[9+9+6]` | `t64r4 X[10+5+5+4]` | 两个方向分别筛选，F 回退保守 L9、B 保留 L10 |
| RZZ/24 | `t128r2 C[9+9+6]` | `t64r4 C[10+10+4]` | forward/backward 独立选择，不允许 B 收益补偿较慢 F |
| XXZ/24 | `t128r3 Zx4` | `t32r3 Zx4` | bond backward 偏好单 warp 的轻 shape |

方向选择使用完整 RX/RY layer 的本方向时间，而不是一次 energy+gradient 中的联合目标。对 RA 22q、SU2 22/24q、RZZ 24/26q 和 QAOA 18/26q，系统保留 `F128r2`，再分别组合 `B64r4`、`B128r3` 或 `B32r2`。这些 backward 半边在方向-only 配对中相对 `B128r2` 为 1.081×--1.168×，而 forward 因配置相同严格记为 1.000×。因此被选择的 backward 不再携带一个已知较慢的 forward geometry，两个方向也都有各自的接受证据。

### 3.6 bit position 是 phase 成本的一部分

24q/28q 的单 phase 扫描同时改变 target 所在的 bit range 和连续性。compact 的位置 spread 中位数为 19.4%，最大 51.6%；fixed-low-5 为 6.2%，pair-low-6 为 7.6%。单候选三轮相对 MAD 中位数低于 1%，说明即使保留低位连续性，高位与更高位也不能完全视为同一成本。

planner 因而将 phase role 分成 `low`、`high-middle` 和 `high-tail`。它允许每个 phase 分别选择 threads、register bits、mailbox 和连续性，再用完整 layer 计时确认。多-shape 驱动发现 28q RX forward 的 `t32r4m1[9] + t32r4m1[9] + t64r4m2[10]` 相对最佳统一 shape 加速 1.083×；其余多数预测候选在真实连续执行中持平或回退，证明单 phase 加和模型只能用于产生 finalists。

phase 几何确定后，mailbox cut 又作为独立的后处理维度扫描。每个有 mailbox 的 phase 分别测试全部合法 `m1/m2/m4…`，局部赢家再组合成完整 layer。相对同几何的全 m1，28q RX backward、RX forward、RY forward 分别达到 1.087×、1.052×、1.137×；但相对原 phase 赢家已有的 m2 配置分别只有 1.009×、0.987×、0.998×。因此 refinement 已进入测试流程，但本轮没有新的 cut 通过接受阈值，生产 dispatch 不变。

## 4. 对角层执行引擎

### 4.1 对角层在一个层端点生成全部梯度

RZ、RZZ 和 CZ 在 computational basis 中对角。每个 amplitude 只需要自己的 basis bits 和一个 complex phase，不需要 partner exchange。更重要的是，同一对角层的生成元两两对易。对

\[
D(\theta)=\prod_j e^{-i\theta_jG_j/2},
\]

\(G_jD=DG_j\)，因此所有 \(\operatorname{Im}\langle\lambda|G_j|\phi\rangle\) 可在同一层端点从一次 `phi/lambda` 读取中归约。系统不需要保存或重建对角门之间的中间态。

这个执行模式同时适用于独立 diagonal pass 和融入 rotation backward 的路径。是否融合取决于少一次 pass 能否抵消更长的 register live range 和更多 partial gradients，而不是由对易性单独决定。

### 4.2 chunk lookup 将三角函数移出 amplitude 循环

对一个 basis index，整个 diagonal group 的 phase 只取决于一组 bit eigenvalues。SAD 将 \(k\) 个 generator 分为一个 chunk，在 host 上为 \(2^k\) 种 code 预计算 complex factor。对 \(g\) 个 generator，表项数为

\[
\left\lceil\frac{g}{k}\right\rceil2^k,
\]

device 内循环只执行 `build code → load factor → complex multiply`，不为每个 amplitude 调用 double-precision `sincos`。

| layer | q | device `sincos` | chunk lookup | speedup |
|---|---:|---:|---:|---:|
| RZ | 16 | 0.00881 ms | 0.00365 ms | 2.41× |
| RZ | 20 | 0.11974 ms | 0.02925 ms | 4.09× |
| RZ | 24 | 2.06783 ms | 0.70110 ms | 2.95× |
| RZ | 28 | 34.14548 ms | 10.95048 ms | 3.12× |
| ring RZZ | 16 | 0.00884 ms | 0.00471 ms | 1.88× |
| ring RZZ | 20 | 0.12042 ms | 0.04724 ms | 2.55× |
| ring RZZ | 24 | 2.07889 ms | 0.75469 ms | 2.75× |
| ring RZZ | 28 | 34.39739 ms | 13.96671 ms | 2.46× |

lookup bits \(k\) 产生一个小型离散取舍：增大 \(k\) 会减少每 amplitude 的 lookup/multiply 数，却使表大小和 host build 成本指数增长。因此 SAD 将 lookup bits、diagonal CTA threads、reduction 策略和 fusion mode 作为与 rotation shape 分离的参数组。

### 4.3 共享参数应改变数据表示

环形 MaxCut QAOA 的 cost eigenvalue 只依赖相邻 bits 不同的数量，即 domain-wall count。一层中的所有 RZZ 共享 \(\gamma_l\)，因此不必建立 \(q\) 组独立 gate factor；一个紧凑域墙 code 就能给出整层 phase，backward 也只产生一个 \(\gamma_l\) gradient。

相对通用 chunk code，domain-wall lookup 在保持同一 rotation 和 fusion 边界时得到：

| q | 10 | 20 | 24 | 28 |
|---:|---:|---:|---:|---:|
| speedup | 1.137× | 1.110× | 1.066× | 1.090× |

这一改进不是 block-size tuning，而是将算法中的参数共享直接编码到 GPU 数据表示。

### 4.4 diagonal 参数的影响是局部且可搜索的

在保持电路其他部分不变的相邻配对中：

| 决策 | 比较数 | 选定策略显著更快 | 2% 内 | 替代/选定 |
|---|---:|---:|---:|---:|
| ordinary lookup k6/k8/k10 | 16 | 4 | 12 | 0.987--1.059× |
| CTA-tree/warp-atomic reduction | 6 | 0 | 6 | 0.995--1.007× |
| ordinary diagonal t64/t128 | 6 | 5 | 1 | 1.014--1.081× |
| QAOA domain-wall/chunk lookup | 4 | 4 | 0 | 1.066--1.137× |
| QAOA diagonal t64/t128/t256 | 8 | 0 | 8 | 0.998--1.002× |

数据表明，lookup 表示本身带来了明确收益，但 \(k\)、threads 和 reduction 没有一个对所有 q 严格占优的常数。SAD 使用少量离散候选；在性能差小于 2% 时选择更简单的共享实现。

## 5. 置换层与边界融合

### 5.1 将整层 CNOT 合成一个置换

CNOT 没有参数，也不产生 gradient。任意连续 CNOT 的复合仍是 computational-basis permutation。对 ring CNOT，SAD 在 host 上得到整层的线性 index map，然后以一次 state pass 完成所有 CNOT，而不是执行 \(q\) 个逐门 kernel。

置换需要双 state buffer 来避免跨 thread 原地写冲突。对每个 amplitude 一读一写的双 buffer 实现，可以选择 gather 或 scatter 方向。精确的 warp-sector 分析给出：

- forward \(U\)：连续读 input，scatter 到 \(P(x)\)；
- backward \(U^\dagger\)：从 \(P(y)\) gather，连续写 output。

| q | forward gather | forward scatter | adjoint gather | adjoint scatter |
|---:|---:|---:|---:|---:|
| 22 | 0.164 ms | **0.136 ms** | **0.144 ms** | 0.243 ms |
| 24 | 1.067 ms | **0.696 ms** | **0.688 ms** | 1.696 ms |
| 26 | 4.184 ms | **2.977 ms** | **3.024 ms** | 7.069 ms |

作为对照，单 buffer 逐 CNOT in-place 需要 \(q\) 次 full-state pass，24/26q 分别比最佳双 buffer 方向慢 12.9×/13.2×。

Controlled-Y 也是 monomial operator：它在受控子空间做置换并附加 `±i` phase，因此可用“index map + phase”扩展相同执行模式。本文对 Controlled-Y 只说明方法可扩展，不将 CNOT 数据当作 Controlled-Y 的实测结果。

### 5.2 最佳 permutation kernel 仍不如消除 permutation pass

当 ring CNOT 紧接 rotation layer 时，forward 可在最后一个 rotation phase 将 amplitude 直接 scatter 到置换后地址；backward 可在第一个 reverse phase 完成 inverse gather。这会从数据流中完全删除独立 CNOT pass。

对 16/20/24q，rotation/CNOT 写回融合将 RA forward 加速 1.04×/1.09×/1.17×，将 SU2 forward 加速 1.06×/1.11×/1.21×。相比之下，仅更换 standalone CNOT 的 gather/scatter 方向对完整 energy+gradient 的改善不超过 1.31%。这区分了两类优化：**地址方向优化一次 pass，边界融合则删除一次 pass。**

融合仍需要满足语义与资源约束。如果中间存在不可重排的层边界，或融合显著增加 index live range 和 register pressure，系统仍保留 split 路径并通过端到端测量选择。

## 6. XX/YY/ZZ 的 bond 执行引擎

### 6.1 双比特 partner 不要求偶数 tile

对 bond \((a,b)\)，XX 和 YY 都在两组 basis states 之间耦合：

```text
00 <-> 11
01 <-> 10
```

对 tile-local index，partner 为

\[
i'=i\oplus2^{s_a}\oplus2^{s_b}.
\]

只要两个 bond qubit 都在 tile 中，tile 自然包含四种 bit 组合。因此 L9 可以容纳 4 个完整 bond 并将剩下 1 bit 作为 filler；偶数 tile 是性能选择，不是正确性条件。

不同 q/direction 的 tile 数据也没有显示统一最佳 L：

| q | direction | L8 `t32r3` | L9 `t128r2` | L10 `t128r3` |
|---:|---|---:|---:|---:|
| 20 | forward | 0.264 ms | 0.275 ms | **0.254 ms** |
| 20 | backward | **0.813 ms** | 0.891 ms | 0.878 ms |
| 24 | forward | **5.391 ms** | 5.725 ms | 5.518 ms |
| 24 | backward | **15.712 ms** | 17.171 ms | 16.250 ms |
| 26 | forward | 29.922 ms | 29.719 ms | **25.395 ms** |
| 26 | backward | **66.911 ms** | 71.926 ms | 69.092 ms |

q26 forward 的 L10 将一个 matching 从 4 phase 降至 3，因而胜出；q24 backward 的 L8 仍为 4 bonds/phase，但以单 warp 和更小 mailbox 取得最佳时间。

### 6.2 同 bond 的 XX、YY 和 ZZ 可代数合并

同一 bond 上的 \(XX\)、\(YY\)、\(ZZ\) 项两两对易。令 \(z\in\{+1,-1\}\) 为 basis parity，三个旋转可合并为一次两振幅更新：

\[
a=c_xc_y+s_xs_yz,\qquad
b=s_xc_y-c_xs_yz,
\]

\[
\psi'_i=e^{-i\theta_z z/2}\left(a\psi_i-i b\psi_{i'}\right).
\]

这一代数折叠使 RXX、RYY 和 RZZ 共享 partner load 和 state writeback，避免三次独立 pass。backward 仍会形成 X/Y/Z 三个 gradient，但可在同一个 tile 生命周期中完成三个 overlap 和两条逆演化。

### 6.3 cross-matching 在不改变依赖的前提下减少 pass

一个 even 或 odd matching 内的 bonds 互不重叠，可以任意重排。相邻 even/odd matching 一般不对易；例如 \(X_0X_1\) 与 \(Y_1Y_2\) 在 qubit 1 上反对易。因此系统不能将整个 even 和 odd layer 无条件合并。

SAD 将 qubits 分为连续 block，在每个 block 内先完成 even bonds，再完成不跨 block 的 internal odd bonds，最后处理 block-boundary odd bonds。被提前的 odd bond 只跨过其他 block 中与它不相交的 even bonds，因而与原始 `all-even → all-odd` 顺序等价。

13 个 q 的相邻配对中，cross-matching 策略在 9 个规模上显著更快，4 个在 2% 内，最大改善为 16.9%。q6 选择 separate matching，显示 pass 合并产生的 metadata 和通用 schedule 开销在极小 state 上可以超过其收益。

## 7. 电路级特化

### 7.1 直接生成已知初态的首层末态

从 `|0…0⟩`、`|+…+⟩` 或 Néel 态出发时，第一层不需要经过通用“清零 state → 置位 basis state → rotation → diagonal → permutation”流水线。对 product rotation，每个 output amplitude 等于若干单 qubit 系数的乘积；diagonal 只乘 phase，permutation 只改变 output index。因此系统可从每个 output basis index 直接写出首层末态。

下表给出第一层 forward 的 `generic/direct` 加速。

| circuit | 8q | 12q | 16q | 20q | 24q | 28q |
|---|---:|---:|---:|---:|---:|---:|
| RA-HEA | 2.83× | 3.82× | 3.75× | 9.42× | 15.50× | 27.27× |
| SU2-HEA | 3.01× | 3.86× | 3.89× | 10.02× | 16.52× | 27.67× |
| RZZ-HEA | 1.90× | 3.22× | 3.26× | 4.13× | 6.82× | 13.60× |

该优化不改变后续 adjoint 语义：它只用同一参数下等价的首层末态替代通用执行序列。QAOA 的 `|+⟩ + cost` 也使用直接生成，但其不同 initializer 在端到端上的差异低于 1%，因此不将局部 initializer 数字当作主要效果量。

### 7.2 使用全局实数不变量

RA-HEA 从实 `|0…0⟩` 开始，RY 和 CNOT 都是实矩阵，该实验中的 X+ZZ Hamiltonian 也保持实数。因此 forward state、\(H|\psi\rangle\) 和 backward 的两条状态始终没有 imaginary component。

SAD 为该电路选择 scalar state，将四个 state buffer 的容量和主要显存流量减半，并用实数 RY/Hamiltonian/gradient kernel 代替 complex 路径。在 4--28q 的 13 个同结构配对中，该路径相对 complex state 快 **1.141×--2.080×**。

这是一个跨 forward、Hamiltonian 和 backward 的电路级不变量，不是 RY kernel 的局部特例。如果电路含 RZ 或 Hamiltonian 含 Y 项，实数闭包不再成立，系统回到 complex state。

### 7.3 融合边界由代数合法性和资源成本共同决定

SAD 不把“融合开/关”作为全局布尔量。对每个电路 layer，系统先检查代数上是否可重排，再在合法边界中比较：

- 减少的 full-state passes 和 launches；
- 增加的 index/lookup 指令；
- 更长的 register live range；
- backward 增加的 partial gradient 与 shared reduction storage。

结构策略的相邻配对展示了融合收益的范围与方向性：

| 决策类别 | 比较数 | 选定策略显著更快 | 2% 内 | 替代/选定 |
|---|---:|---:|---:|---:|
| SU2 forward | 26 | 17 | 9 | 0.983--1.140× |
| SU2 backward | 26 | 25 | 1 | 1.014--1.473× |
| RZZ forward | 13 | 10 | 3 | 1.004--1.171× |
| RZZ backward | 26 | 23 | 3 | 1.009--1.339× |
| QAOA forward | 13 | 6 | 7 | 0.998--1.053× |
| QAOA backward | 13 | 9 | 4 | 0.999--1.114× |

backward 融合的收益通常大于 forward，因为它能同时消除两条 state 的中间往返。但 QAOA forward 有近一半规模在 2% 内，说明“少一次 pass”仍可被更复杂的 cost code 和 live range 抵消。

## 8. 配置合成

### 8.1 搜索空间的结构

配置不是一个可用统一公式求解的 block size。它包含五组参数：

1. **layer structure**：fused/split、CNOT data direction、XXZ cross/separate；
2. **rotation execution**：forward/backward \(t,r\)、phase division 和 slot map；
3. **on-chip resources**：mailbox split，以及由 registers/shared 推导的 active CTA 台阶；
4. **diagonal execution**：lookup bits、threads、reduction 和 fusion mode；
5. **bond execution**：tile width、bond ownership 和 dependency-preserving schedule。

如果直接取完全直积，仅 \(q=28\) 的 phase division 就有 \(2^{27}\) 种。大部分组合可以用合法性、phase 下界和资源上限在执行前删除。

### 8.2 分层候选生成

SAD planner 使用以下顺序缩小搜索。

1. **Semantic legality.** 仅保留不改变门序偏序、参数归属和 generator 所有权的 fusion/schedule。
2. **Pass lower bound.** 对每个 shape 计算理论最少 phase \(P_{min}\)，通常只保留 \(P_{min}\) 和少量有 locality/resource 理由的 \(P_{min}+1\)。
3. **Direction-local primitives.** forward 和 backward 分开测量；对每个 shape/continuity 扫描低位、中高位和最高位 phase 的 `ms` 与 `ms/gate`，不允许一个方向的收益补偿另一个方向的回退。
4. **Heterogeneous schedule generation.** 从 compact 装满、近均分、fixed-low-5 和 pair-low-6 出发，用动态规划生成 phase division；不同 phase 可以选择不同的 threads、register bits、mailbox split 和连续性。
5. **Resource pruning.** 删除无法编译、发生 spill，或在 phase 数、registers 和 shared memory 上同时被支配的候选。mailbox 只在切分可能跨过 active-CTA 台阶时进入测量。
6. **Layer then end-to-end selection.** 先在同一 binary、同一 state 上执行完整方向 layer，淘汰把孤立 phase 时间错误相加得到的候选；再把各方向赢家组合起来做完整 energy+gradient 配对。差异不超过 2% 时，系统选择更简单、可在相邻 q 复用的规则。

这一方法最终在 65 个场景中只需要 14 种编译 variant，而非为每个场景编译新 kernel。其中 3 种是方向独立选择产生的混合 variant：`F128r2/B64r4`、`F128r2/B128r3` 和 `F128r2/B32r2`。phase plan 通过 runtime metadata 复用这些 variant。

### 8.3 小 state 和大 state 需要不同 shape

在小 q 上，过大 tile 的展开指令、空闲 threads 和同步可以高于减少 phase 的收益。因此 4/6/10/12/14q 的大多数路径使用 L7 `t32r2`，8/16q 使用 L8 `t64r2`；到 20q 以上，带宽和 pass 数的权重上升，系统在 L9/L10 之间按电路和方向选择。

对照策略保持完全相同的 layer fusion、diagonal 和 CNOT 布局，只将所有场景固定为 `F128r2/B128r2` 和 canonical phase。下表是 SAD planner 相对该保守配置的完整 energy+gradient 加速。

| circuit | 4q | 8q | 12q | 16q | 20q | 24q | 28q |
|---|---:|---:|---:|---:|---:|---:|---:|
| RA-HEA | 1.213× | 1.190× | 1.297× | 1.085× | 1.141× | 1.235× | 1.224× |
| SU2-HEA | 1.336× | 1.207× | 1.352× | 1.068× | 1.000× | 1.099× | 1.126× |
| RZZ-HEA | 1.187× | 1.181× | 1.313× | 1.035× | 1.000× | 1.046× | 1.113× |
| QAOA | 1.332× | 1.268× | 1.475× | 1.067× | 1.000× | 1.000× | 1.217× |
| XXZ-HVA | 1.159× | 1.097× | 1.728× | 1.084× | 1.000× | 1.095× | 1.104× |

65 个场景中，planner 在 55 个场景上超过 2% 阈值，10 个场景与保守配置持平，没有场景选择显著更慢的配置。最大收益 1.728× 出现在 12q XXZ-HVA，说明小规模同样需要 shape dispatch，而不是只在大 state 上调参。

### 8.4 planner 以 wall time 为目标，而不是某个硬件 counter

pass 数、occupancy、L2 hit rate、DRAM bytes 和 barrier stalls 都能帮助解释候选，但任何一个 counter 都不足以作为选择目标。一个 cache-blocked RX/RY 实现可将 24q 的 DRAM read 从约 750 MiB 降至 586 MiB，但也会增加 chunk launches、mapping 和写回。

| q | ordinary | 64 MiB blocked | wall-time effect |
|---:|---:|---:|---:|
| 22 | 0.614 ms | 0.701 ms | -14.2% |
| 23 | 1.561 ms | 1.478 ms | +5.3% |
| 24 | 3.133 ms | 3.086 ms | +1.5% |
| 25 | 6.208 ms | 6.283 ms | -1.2% |
| 26 | 13.432 ms | 13.496 ms | -0.5% |

将 blocking 与选定的 phase plan 联合测量时，q22--q24 的 RX/RY forward/backward 均无收益，persisting hint 的最大可复现改善为 0.48%。因此 L2 数据只用于解释性能，不进入 dispatch feature；所有候选的最终目标是同步后的端到端 wall time。

## 9. 评估概览

### 9.1 实验设置

评估平台为 NVIDIA RTX 6000 Ada（SM 8.9，48 GiB），使用 float64、8 layers 和固定随机种子 42。五类电路均覆盖偶数 4--28q，共 65 个场景。每个 wall time 包含完整 forward、Hamiltonian 和全梯度 backward，并在 GPU 同步后计时。

基线直接调用预构造的低层 `lightning_gpu_ops`，不包含 QNode、Autograd 或 transform 开销。这保留了 Lightning 的 GPU gate kernels，同时避免将框架开销当作 SAD 的系统收益。

### 9.2 端到端结果

| circuit | 4q | 8q | 12q | 16q | 20q | 24q | 28q |
|---|---:|---:|---:|---:|---:|---:|---:|
| RA-HEA | 48.68× | 44.71× | 35.51× | 20.14× | 10.42× | 24.23× | 20.63× |
| SU2-HEA | 80.39× | 39.00× | 37.11× | 28.33× | 8.15× | 16.24× | 15.84× |
| RZZ-HEA | 74.35× | 40.11× | 37.85× | 22.73× | 8.91× | 18.27× | 17.77× |
| QAOA | 88.22× | 46.17× | 33.88× | 32.19× | 8.55× | 16.51× | 17.56× |
| XXZ-HVA | 69.23× | 27.63× | 28.15× | 19.38× | 4.18× | 9.26× | 9.12× |

在所有 65 个场景上，SAD 相对 Lightning GPU native 的加速范围为 **4.18×--88.22×**。小 q 的高比率同时反映了逐门 host/native 边界与 kernel-launch 消除；大 q 的结果更主要反映 full-state pass、带宽和 backward 归约的改善。因此本文不将最大加速比作为大规模吞吐的代表数，而同时报告完整 q 范围。

### 9.3 结构策略与数值正确性

结构、diagonal 和 bond schedule 共包含 191 个单变量候选、727 组交替配对样本。在 2% 阈值下，SAD 选定的策略在 125 个比较中显著更快，66 个比较中持平，没有 alternative 显著更快。这些比较每次只改变一个结构决策，保持输入、shape、phase plan 和其他 fusion 不变。

最终 65 个 Lightning 对照场景的最大 energy 绝对误差为 `6.57e-14`，完整梯度的最大元素绝对误差为 `8.54e-13`。结构单变量配对的最大 energy/gradient 误差为 `1.42e-14/2.00e-13`。

### 9.4 证据的作用边界

不同数据回答不同问题：

- microbenchmark 和 profiler counter 用于证明机制，例如 mailbox barrier、lookup 或 CNOT sectors；
- 同结构配对用于归因单个 planner/fusion 决策；
- Lightning 端到端对照衡量 layer representation、专用 kernel、fusion 和 dispatch 的组合效果。

因此，局部 kernel 的 10%--50% 改善不应与端到端加速相乘；同样，4.18×--88.22× 也不能归因给某一项单独技术。

## 10. 适用范围与局限

SAD 的设计目标是可识别 layer template 的变分电路，而不是取代任意 gate list 的通用模拟器。一个新电路家族需要声明层级参数布局、对易/依赖关系和合法融合边界；无法识别的片段需要回退通用执行。

实验中的具体 dispatch 边界来自 RTX 6000 Ada、float64 和 8-layer 工作量。layer algebra、pass 合并和 forward/backward 不对称可以迁移到其他 GPU，但 `t64r4`、lookup `k8` 或某个 q 边界不是跨设备常数。在新架构上，planner 需要重新校准少量 finalists。

diagonal lookup 在一次 `energy_and_grad` 执行前由 host 构建并上传。对 k8、8 layers，SU2 的 RZ 表构建约 0.28 ms，RZZ-HEA 的 RZ+RZZ 约 0.55 ms；在 24--28q 上相对整步时间较小，但对小 q 或更大 \(k\)，它应作为 optimizer-step 成本计入。

statevector 本身仍以 \(O(2^q)\) 增长。SAD 减少的是结构化电路在给定 q 下的 passes、launches 和中间数据移动，不改变状态向量模拟的指数空间复杂度。
